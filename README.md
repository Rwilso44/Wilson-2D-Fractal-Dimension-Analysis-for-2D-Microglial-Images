Brief READ ME

Assumptions of this program: 
(a) Your images are pre-processed to only include Iba1+ cells that are colocalized with DAPI
(b) Images are already masked and therefore binary

Steps:
(1) Place the boxcount.R program in your chosen working directory - the folder with your images for analysis
(2) Run the analyze_boxcount.R in R or R studio
(3) Note: If running an individual file, change the bottom section of analyze_boxcount.R
(4) Output will be in wd
